Privacy Policy

Last updated: 8 November 2026.

"automation-oauth" is a personal automation tool run by Artem Kapeliush. It connects to Google services only with the account owner's consent, to run the owner's own workflows.

Data we access

Only the Google data the account owner authorizes (for example files in Google Drive, Docs or Sheets). Access is limited to the scopes shown on the consent screen.

How we use it

Data is used only to run the automations the owner configured. It is not sold, shared with third parties, used for advertising, or used to train AI models.

Storage and retention

OAuth tokens are stored in the owner's own n8n instance. Workflow data stays in that instance. The owner can revoke access at any time at myaccount.google.com/permissions, and tokens are then deleted.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
